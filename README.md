# 漫画装订工坊

纯静态浏览器应用，部署于 GitHub Pages。无需构建，无第三方 JavaScript 依赖，图片在浏览器本地处理。

支持图片、文件夹、ZIP/CBZ 导入；自然排序、章节重命名与排序、按章节分册、缩放、灰度、对比度与裁白边；导出带封面和目录的固定版式 EPUB 3 或 CBZ。

请使用新版 Chrome / Edge。ZIP 支持 Store / Deflate，不支持加密、ZIP64 和 RAR。大量图片建议分批导入；浏览器内存限制仍适用。PDF / MOBI / AZW3 尚不支持，实体阅读器兼容性需自行检查。

在仓库 Settings → Pages 选择 Deploy from a branch、main、/(root) 即可发布。
